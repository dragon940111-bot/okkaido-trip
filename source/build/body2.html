  • 기존 #16처음 PDF 일정표에 있던 곳. 숫자 = PDF 번호.
  • 신규이번에 새로 넣은 곳.
  • 선택 · 신규시간 되면 들르는 곳. 빼도 됨.
  • 3그날 지도 번호 (상세 일정 번호랑 같음).
  • 11/2 ✅그날 영업 확인됨. ⚠ = 영업일인데 한 번 더 확인, ❌ = 그날 휴무.
  • 食べログ 3.80타베로그(일본 맛집 평점). 3.5↑ 상위권, 3.6↑ 지역 최상위권. 구글은 ★점수(리뷰 수).
  • 이동차·지하철 이동 구간.
  • + 대안 맛집같은 시간·동선으로 갈 수 있는 다른 가게. 펼치면 바꿨을 때 일정이 어떻게 달라지는지 나옴.
  • + 자유시간자유시간에 들를 만한 곳. "일정 조정" 줄 있으면 시간 더 걸리는 곳.
  • A–G일정 변경 대안. 하루(또는 반나절)를 다른 코스로 바꾸는 안. 대안마다 시간표·맛집·지도 접혀 있음.
  • 가게 공식 사진가게가 타베로그에 직접 올린 사진. 메뉴 이름표 붙은 건 가게·촬영자 허락 받고 넣은 사진. 장소·동네 사진은 다 실제 그곳 사진.
  • ¥가격은 엔화, 대부분 1인 기준 (¥1,000 ≈ 1만 원 안팎).

예보가 바뀌거나 다른 데 가 보고 싶을 때 하루(E·F는 반나절)를 바꾸는 대안 7개(A–G). 삿포로 시내 보고 싶으면 F(11/2 오후)나 G(11/5 하루). 제목 누르면 요약 나옴 — 윗줄 지금 일정, 아랫줄 바꾼 뒤. 진한 칸만 바뀌는 날. 맨 아래 "바뀌는 날 상세 일정" 누르면 시간표·맛집·지도 다 나옴. 흐린 "그대로" 줄은 원래 일정이랑 같은 부분.
