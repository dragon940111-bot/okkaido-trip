# 첫 메시지 프롬프트

프로젝트를 만들고 파일을 올린 뒤, 그 프로젝트 안에서 **처음 한 번** 보내는 메시지임. 아래 블록을 그대로 복사해서 보내면 됨.

```
지금부터 홋카이도 여행(2026-11-02~11-06) 계획을 Claude에게서 이어받는 거야.
프로젝트에 올린 파일을 전부 끝까지 읽어 줘. 순서는 이렇게:
1) 00_인계문서_ChatGPT.md
2) 여행정보_전체.md
3) 운전가이드_전체.md
4) 나머지 파일

다 읽었으면 아래 5가지를 한국어로 답해 줘.
1. DAY 1–5를 하루에 5줄 이내로 요약(지역, 점심·저녁 메인 식당, 주요 볼거리, 숙소 도착 시각).
2. 예약하거나 미리 전화해야 하는 곳 목록(날짜·시각·전화번호).
3. 일정 변경 대안 A–G를 한 줄씩(언제 쓰는지).
4. 네가 할 수 있는 것 / 못 하는 것을 짧게. 특히 아래 세 가지를 확실히 말해 줘.
   - 음성 모드에서 이 파일들을 참고할 수 있는지
   - 인터넷 검색이 되는지
   - 공유 페이지를 직접 고칠 수 있는지
5. 계획 보고 네 생각에 더 좋게 바꿀 만한 데 있으면 자유롭게 말해 줘.

틀린 데가 있으면 내가 바로잡을게. 그다음부터는 여행 중에 짧게 물어볼 거야.
```

## 음성으로 물어볼 예시

시험해 볼 때나 여행 중에 그대로 말하면 됨.

**식당·일정**
- "오늘 점심 메인 어디야?"
- "대안 식당은 뭐 있어? 메인이랑 뭐가 달라?"
- "메인 식당 주변에 같이 들를 만한 데 있어?"
- "지금 몇 시인데, 다음 일정까지 시간 괜찮아?"
- "오늘 저녁 예약해야 돼? 전화번호 알려 줘."
- "거기 주차 돼? 라스트오더 몇 시야?"
- "줄이 너무 길어. 근처 대안으로 바꾸면 일정 어떻게 돼?"

**날씨·일정 변경**
- "내일 비 온대. 일정 바꾸는 게 나아?" (→ 대안 C 등)
- "오늘 너무 피곤한데 북쪽 루프 대신 삿포로 시내로 바꾸면?" (→ 대안 G)
- "방금 정한 거 변경 메모로 정리해 줘."

**숙소·렌터카·운전**
- "숙소 주소랑 주차 어떻게 해?"
- "공항에서 렌터카 영업소 어떻게 가?"
- "렌터카 반납 전에 주유는 어디서 해?"
- "이 표지판 止まれ 뭐야?"
- "코인파킹 요금표 어떻게 봐?"
- "ETC 차로로 들어가도 돼?"
- "사고 나면 어떻게 해?"

**공유 페이지 수정 (글로 요청)**
- "내일 점심을 대안 2번으로 바꾸고 공유 페이지에도 반영하게 Codex 작업 요청문 만들어 줘."
